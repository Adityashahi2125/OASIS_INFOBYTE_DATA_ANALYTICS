# OASIS INFOBYTE — Data Analytics Internship

## Level 2 — Task 1: Predicting House Prices with Linear Regression

### Objective
Predict median house values using Linear Regression.

### Dataset
California Housing dataset from Scikit-learn. The notebook loads it automatically.

### Workflow
- Data inspection and descriptive statistics
- Missing-value check
- Correlation analysis
- Feature-target visualisation
- Train/test split
- Linear Regression
- MAE, RMSE and R²
- Actual vs predicted plot
- Coefficient analysis
- Residual analysis
- Business interpretation and limitations
