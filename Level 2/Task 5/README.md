# OASIS INFOBYTE — Data Analytics Internship

## Level 2 — Task 5: Autocomplete and Autocorrect Data Analytics

### Objective
Use text analytics to understand word patterns and implement basic autocomplete and autocorrect systems.

### Covered
- Text cleaning and tokenization
- Word-frequency analysis
- Bigram and trigram analysis
- Prefix autocomplete
- Context-aware next-word suggestions
- Levenshtein edit distance
- Frequency-based autocorrect
- Vocabulary-size analysis
- Practical recommendations and limitations

### Dataset
NLTK Gutenberg corpus. The notebook downloads it automatically.

### Run
Open `notebook/Task_5_Autocomplete_Autocorrect_Data_Analytics.ipynb` in VS Code/Jupyter and run cells from top to bottom.
