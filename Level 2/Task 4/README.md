# OASIS INFOBYTE — Data Analytics Internship

## Level 2 — Task 4: Unveiling the Android App Market

### Objective
Analyse the Google Play Store app market using exploratory data analysis.

### Covered
- Data cleaning and duplicate-app handling
- Rating analysis
- Category analysis
- Install reach
- Reviews
- Free vs paid apps
- Price distribution
- Content rating
- Top apps by installs and reviews
- Ratings vs popularity
- Business insights and recommendations

### Dataset
Google Play Store Apps dataset (`googleplaystore.csv`), approximately 10,841 raw rows and 13 columns.

Download:
https://www.kaggle.com/datasets/lava18/google-play-store-apps

Place the CSV in the `data` folder before running the notebook.
