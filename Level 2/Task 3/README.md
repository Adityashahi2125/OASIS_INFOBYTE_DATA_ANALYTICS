# OASIS INFOBYTE — Data Analytics Internship

## Level 2 — Task 3: Fraud Detection

### Objective
Detect potentially fraudulent credit-card transactions using machine learning.

### Models
- Logistic Regression with class weighting
- Random Forest with balanced class weighting

### Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- PR-AUC
- ROC-AUC
- Confusion matrix
- Precision-Recall curve
- Probability threshold analysis
- Feature importance

### Dataset
ULB Credit Card Fraud Detection dataset.
Download `creditcard.csv` from:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Place the CSV in the `data` folder before running the notebook.

### Important
Fraud is a highly imbalanced class, so accuracy must not be used as the only performance measure.
