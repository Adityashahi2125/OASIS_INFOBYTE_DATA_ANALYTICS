Dataset: Credit Card Fraud Detection
Original source: ULB / Worldline research dataset, commonly distributed via Kaggle.

Kaggle dataset:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Required file:
creditcard.csv

Place it here:
OASIS_INFOBYTE_DATA_ANALYTICS/Level_2/Task_3_Fraud_Detection/data/creditcard.csv

The dataset contains anonymized V1-V28 features, Time, Amount and Class.
Class 0 = legitimate; Class 1 = fraud.
