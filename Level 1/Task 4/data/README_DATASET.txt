Dataset: NLTK Movie Reviews corpus
Task: OASIS INFOBYTE Data Analytics — Level 1, Task 4

The notebook downloads the public NLTK Movie Reviews corpus automatically:
    nltk.download("movie_reviews")

The corpus contains 2,000 labelled movie reviews:
- 1,000 positive
- 1,000 negative

Reference:
https://www.nltk.org/nltk_data/

This avoids placing a large external dataset file inside the project ZIP.
