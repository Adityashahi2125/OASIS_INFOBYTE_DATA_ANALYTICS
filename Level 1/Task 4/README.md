# OASIS INFOBYTE — Data Analytics Internship

## Level 1 — Task 4: Sentiment Analysis

### Objective
Classify movie reviews as positive or negative using NLP and machine learning.

### Dataset
NLTK Movie Reviews corpus — 2,000 labelled reviews (1,000 positive and 1,000 negative). The notebook downloads the corpus automatically.

### Workflow
- Text inspection
- Sentiment distribution
- Text cleaning
- TF-IDF feature extraction
- Logistic Regression
- Accuracy / precision / recall / F1
- Confusion matrix
- Important positive/negative words
- New-review prediction

### Run
Open `notebook/Task_4_Sentiment_Analysis.ipynb` in VS Code/Jupyter.
Select the same Python/Data kernel used for the previous tasks.
Run cells from top to bottom.
The first setup cell downloads the public corpus automatically.
