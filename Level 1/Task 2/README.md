# OASIS INFOBYTE — Data Analytics Internship

## Level 1 — Task 2: Customer Segmentation Analysis

This project segments customers using K-Means clustering on Age, Quantity, Price per Unit and Total Amount.

### Dataset note
The provided retail dataset contains 1,000 transactions and 1,000 unique Customer IDs. Therefore, classic RFM Frequency/Recency variables would not provide meaningful separation. The notebook explicitly handles this limitation and uses the available customer/transaction attributes instead.
